# Daymark — Habit Tracker

Daymark is a responsive, browser-based habit tracker for daily routines and personal goals.

**Live demo:** https://avi-808.github.io/daymark-habit-tracker/

## Features

- Mark daily habit check-ins in a monthly calendar.
- Set weekly targets for habits and compare completed check-ins with those targets.
- Review daily consistency and progress by habit with charts.
- Create weekly, monthly, and yearly goals and update progress.
- Organize habits across study, home, health, and personal areas.
- Save data in the current browser using local storage. No account or server is required.

## Use

Open `index.html` in a modern browser. Add or edit habits, select a month, and click a day to record a completion. Save or export a browser backup before clearing browser data or moving to another device.

## Privacy

Habit check-ins and goals stay in the browser's local storage on the device where they were entered. Publishing the source code does not publish a visitor's private tracker data.
